Para José — cómo cargar creativos reales

Cada imagen se define en el arreglo CREATIVOS dentro del código de esta página (o, más adelante, en una fila de una hoja publicada como CSV, igual que el catálogo).

Cada entrada necesita: imagen_url (debe estar en un hosting que permita CORS — GitHub Pages funciona bien; los links directos de Google Drive normalmente NO funcionan para esto), formato (reel / youtube / carrusel), producto, y las coordenadas codigo_x / codigo_y en píxeles de la imagen original donde debe imprimirse el código.

Las coordenadas dependen de dónde dejaste el espacio en blanco en cada diseño — si me compartes cada imagen te calculo yo mismo esas coordenadas exactas.
